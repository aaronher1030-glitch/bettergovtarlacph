# Contributing

Thank you for helping make public information easier to find and verify. This is an early-stage, independent project. Contributions should improve source quality, accessibility, clarity, and maintainability.

## Before making a change

- Check the existing [project documents](README.md#project-documents) and open issues for duplicate work.
- For new records, use the [data source register](docs/DATA_SOURCES.md) and include the original source URL.
- For budget/project records, verify fiscal year, amount type, responsible agency, and geographic match. Mark uncertainty rather than guessing.
- Do not add personal, confidential, or restricted information.
- Do not imply LGU or BetterGov approval, affiliation, or endorsement.

## Proposing a change

1. Open an issue describing the problem or proposed improvement.
2. For a code/document change, use a focused branch and pull request.
3. Explain the source, evidence, and any limitations in the pull request.
4. For corrections to a source record, provide the official replacement link and date checked.

## Review standard

Reviewers should be able to trace factual statements to a primary source. Budget/project claims need a clear source, period, amount type, and geographic scope. Interpretive claims should be identified as analysis and reviewed cautiously. Uncertain data must remain labeled as uncertain.

## BetterGov contributions

This repository is for the Concepcion project. Contributions to BetterGov's template or directory belong in their respective repositories and should follow the current BetterGov contribution instructions. The BetterLGU directory's guide recommends registering a new portal as Planned if Concepcion is not already listed; directory updates are separate pull requests and are not implied by contributing here.
