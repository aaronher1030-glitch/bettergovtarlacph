## Inclusion rules

- Keep a direct URL to the original publisher wherever possible.
- Record the source's stated date and the date this project checked it.
- For finance and projects, state whether a number is proposed, appropriated, estimated, awarded, disbursed, or otherwise defined.
- State geographic scope and how it was established. A town name in a project title is not conclusive proof of location.
- Record duplicate, ambiguous, broken, or excluded items and explain why.
- Link to public records; do not copy restricted files or personal information into this project.
