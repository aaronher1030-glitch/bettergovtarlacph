# Information and Data Checklist

Use this as a discovery inventory. Start with public sources; do not request or copy restricted records. Record unknowns explicitly rather than guessing.

## Source register fields

For every page, dataset, or document, record:

| Field | What to capture |
|---|---|
| Record ID | Stable local identifier |
| Title / topic | Plain-language label |
| Publisher / owning office | LGU office, agency, or third party |
| Primary URL | Original source, not a repost |
| Record type | Service guide, ordinance, budget, bid notice, project, audit report, etc. |
| Date published / updated | As shown by source; mark unknown if absent |
| Date checked | When the project last verified link/content |
| Fiscal year / coverage dates | When applicable |
| Geography | Municipality, barangay, province, national, or unclear |
| Amount type / unit | Appropriation, ABC, award, payment, etc.; never just “cost” |
| Match method | Exact official ID, API identifier, title match, manual review |
| Limitations | Missing pages, namesake risk, incomplete coverage, scan quality |
| Status | Verified link, needs review, stale, broken, excluded |
| Reviewer / notes | Internal review metadata; avoid personal data |

## Public information categories to inventory

### Existing municipal information

- Official municipal home page and official social channels
- Offices, responsibilities, public contact details, office hours
- Citizen’s Charter and service requirements, fees, and processing time
- Ordinances, resolutions, executive orders, and legislative records
- Bidding documents, bid notices, award notices, and procurement plans
- Public budget documents and financial statements available through official channels
- Development plans and annual investment/program documents, if publicly posted
- Barangay directory and public notices
- Existing e-services and their official provider/terms

### External public records

- DILG Full Disclosure Policy documents for Concepcion, with posted period and file source
- COA reports verified to be for Municipality of Concepcion, Tarlac and the correct year
- DBM/BetterGov budget/project records, documenting geography and matching limits
- PhilGEPS procurement records, retaining procuring entity and notice/award identifiers
- Relevant national agency projects, clearly separating municipal projects from projects merely located nearby

## Questions for source owners

- Is this the canonical/current URL for the record?
- Which office is responsible for updating it, and how often?
- Does a newer version exist, and how can the portal detect it?
- Are there public records that are missing online but can be linked or published officially?
- What context is needed so the record is not misinterpreted?
- Are there privacy, security, copyright, or records-retention limits on reuse?
- Who should receive a correction request when a source is wrong or stale?

## Data classification for the project

- **Public and linkable:** official public web pages and publicly released records.
- **Public but context-sensitive:** budgets, procurement, audit findings, project locations; include definitions, dates, scope, and caveats.
- **Do not ingest for the pilot:** personal identifiers, case-level welfare/health/civil-registry records, credentials, internal drafts, restricted files, or information provided in confidence.
- **User-submitted leads:** keep separate from verified records; review before publication and define moderation/privacy rules first.

## Validation checklist for budget/project records

- Is this an appropriation, proposed allocation, procurement estimate, contract award, disbursement, or completion record?
- Is the responsible agency the Municipality, DPWH, another national agency, or a barangay?
- Does the source explicitly identify Concepcion, or is the match based on title/place-name only?
- Could this be another place with the same/similar name?
- Can the source page/document and fiscal year be opened by a resident?
- Is the record a duplicate across data releases or budget stages?
- Is the interpretation stated as a factual source description rather than an allegation?
- Are excluded/uncertain matches listed with reasons?
