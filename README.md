# Better Concepcion

An independent civic technology project exploring how residents can more easily find and understand public information about Concepcion, Tarlac.

> **Project status: discovery and proposal preparation.** This repository is not an official Municipality of Concepcion website, service, or partnership. The project is not endorsed by the LGU or BetterGov.ph unless they explicitly say so.

## Why this project

The municipality already publishes services and public materials across its website and related sources. This project aims to make those sources easier to discover, connect records to their original publishers, and explain their dates, scope, and limitations. It should complement official channels, not replace them.

## Proposed first release

Begin with a static, mobile-friendly directory of links to verified public records and services. If municipal budget/project data can be accurately scoped, a later phase may use the [BetterGov.ph transparency-portal template](https://github.com/bettergovph/transparency-portal).

The first release will not process applications or payments, collect accounts or sensitive resident information, or present analysis as an official finding.

## Principles

1. Link to primary sources and show publisher, date checked, fiscal year, and geographic scope.
2. Distinguish source facts from estimates, interpretation, and user-submitted leads.
3. Make missing information, uncertain matches, and exclusions visible.
4. Never treat an appropriation as proof of spending or delivery.
5. Keep the project accessible, mobile-friendly, and maintainable.
6. Do not use official branding or imply government endorsement without permission.

## BetterGov alignment

BetterGov's BetterLGU guide recommends checking its directory first, avoiding duplicate portals, starting from public sources, selecting an appropriate template, and planning ongoing maintenance. If this project proceeds as a BetterLGU portal, we will follow the current [BetterLGU guide](https://github.com/jmacj/better-lgu-directory/blob/main/GUIDE.md). The guide says an LGU not listed in the directory can be registered as **Planned** through a contribution to the directory repository.

For a budget portal, follow the separate [budget portal guide](https://github.com/jmacj/better-lgu-directory/blob/main/BUDGET_GUIDE.md): check the budget directory, use the transparency-portal template, validate project matching, disclose exclusions, and add the portal to the directory only once live. Appropriations are not expenditures, and municipal project matching may be incomplete.
